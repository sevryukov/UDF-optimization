# Задание 2: Оптимизация

**Основные изменения:**
- Замена вызовов скалярных функций на **CTE `WorkItemCounts`** с группировкой по `Id_Work`.
- Добавлен фильтр `WHERE Id_Analiz NOT IN (SELECT Id_Analiz FROM Analiz WHERE Is_Group = 1)` – сохранена логика исключения групповых анализов.
- Формирование `FULL_NAME` через `LEFT JOIN Employee` с очисткой символов и fallback на `Login_Name`.

**Использованный AI‑промпт:**
> Перепиши F_WORKS_LIST на set-based. Замени скалярные функции на CTE. Исключи групповые анализы (is_group=1). FULL_NAME делай через JOIN.

**Результат:** время выполнения сократилось с 8.5 с до ~1.1 с (≈7.7x).
